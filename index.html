⚡ Powerful Features

Recipient Manager

Store companies, HR names, emails, positions. Select recipients with checkboxes. Import/export CSV.

Email Templates

Use dynamic tags like {company}, {hr_name}, {position}. Preview before sending.

Attachments

Attach PDF, DOCX, TXT. Auto‑deduplicate. Preview files inside the app.

Smart Scheduling

Set resend intervals (1‑7 days) and max resends. Stop resend per recipient anytime.

AI Assistant (Real)

Connect to OpenAI, DeepSeek, HuggingFace or custom endpoints. Generate resumes & cover letters.

Secure Credentials

Passwords stored in Windows Credential Manager, never in plain files. App passwords for Gmail.

Full History & Logs

Track sent emails, failures, resends. Export history to CSV.

Gmail Integration

Scan job alert emails, parse job details, auto‑generate drafts with AI.

📘 How to Use

1. Configure

Enter your email & app password (Gmail). Save securely to Windows Credential Manager.

2. Add Recipients

Add companies, HR names, emails. Tick checkboxes to select them for sending.

3. Write Template

Use tags like {company} in subject/body. Preview with sample data.

4. Attach Files

Add resume, cover letter, etc. They will be included in every email.

5. Send / Schedule

Send immediately or schedule recurring sending with resend limits.

🔐 Privacy Policy

Your email credentials are never saved to disk. They are stored securely in Windows Credential Manager (local, encrypted).

When you use AI features (OpenAI, DeepSeek, etc.), your job descriptions and prompts are sent to the respective AI provider – we do not store them. No data leaves your PC except for AI API calls and email sending via SMTP.

Gmail integration uses OAuth 2.0 – tokens are stored locally and never shared. You can revoke access anytime from your Google account.

By using this software, you agree that you are responsible for complying with the terms of service of your email provider and AI services.

Full source code available on GitHub for audit.
